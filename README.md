# Karan Bhavnani — Personal Portfolio

A responsive, dark-premium personal portfolio built with plain HTML, CSS and JavaScript.

## Local preview

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

## GitHub Pages

This repository is configured for the GitHub Pages Actions deployment workflow in `.github/workflows/pages.yml`.

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. The workflow deploys automatically on pushes to `main` and can also be run manually.

Expected site URL: https://karanbhavnani.github.io/

## Before sharing publicly

- Replace the LinkedIn placeholder URL with your exact profile URL.
- Review the career title, metrics and project descriptions for accuracy and comfort with public disclosure.
- Keep employer-sensitive architecture, names, data and implementation details out of the site.
- Add a professional portrait if desired.

The site has no build step or runtime dependencies. Google Fonts are optional and fall back to system fonts.
